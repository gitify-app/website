---
title: "How do keyboard shortcuts work?"
category: "Using Gitify"
order: 5
---

Gitify includes keyboard shortcuts for common actions:

- `h` — go home
- `n` — open My Notifications
- `w` — toggle focused mode (participating only)
- `f` — open Filters
- `i` — open My Issues
- `p` — open My Pull Requests
- `r` — refresh notifications
- `s` — open Settings
- `a` — open Accounts (from Settings)
- `q` — quit the app

You can also set a global shortcut to show or hide Gitify from **Settings → System → Global shortcut**.
